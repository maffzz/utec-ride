# 🚗 utec ride - carpooling para la comunidad utec

[![sitio web](https://img.shields.io/badge/🌐-sitio_web-2ea44f?style=for-the-badge)](https://maffzz.github.io/utec-ride/)

✨ plataforma de carpooling diseñada exclusivamente para la comunidad utec, facilitando los viajes compartidos entre estudiantes.

## 🌟 características

- 🚘 publica y busca viajes compartidos
- 📍 ruta directa al campus utec
- 🔐 autenticación segura para estudiantes
- 📱 interfaz intuitiva y fácil de usar
- 💰 ahorra en costos de transporte
- 🌱 contribuye a reducir la huella de carbono

## 🛠️ tecnologías utilizadas

- html5, css3 y javascript puro
- diseño responsivo
- almacenamiento local para una experiencia sin conexión

## 🚀 cómo usar

1. visita [maffzz.github.io/utec-ride/](https://maffzz.github.io/utec-ride/)
2. inicia sesión con tu cuenta utec
3. publica un viaje o únete a uno existente
4. ¡disfruta del viaje compartido!
